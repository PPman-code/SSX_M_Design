# 开始 AI 记录说明弹窗

在当前 Vue 2 项目实现或校正本包范围。先定位现有接入点和同类组件，复用其基础能力，按交付视觉覆盖该业务实例。

1. 打开 [离线状态对照](离线状态对照.html)，按 [视觉规格](视觉规格.md)、[最终计算样式](final-visual.css) 和 [样式接入](样式接入.md) 对齐浅色视觉。
2. 读取 [状态与路由](状态与路由.md) 及 [交互与数据](交互与数据.md)，按目标项目接入。可用 [验收数据](验收数据.json) 复现。
3. 按 [验收用例](验收用例.md) 验证，回传 390 CSS px 浅色状态对照截图，并检查 360/375/430 CSS px 的换行、滚动、操作区和遮挡。
4. 核对 [接口与权限待确认](接口与权限待确认.md)，说明复用组件、验收结果及实际联调缺口。

离线页展示已采集的状态截图。最终 CSS 是关键元素的计算样式参考，按目标 DOM 与状态映射。
