# 视觉基础与移动端差异

## 保留 PC 基础
品牌色、状态色、中性色与 Light/Dark 角色继承 PC；保持 Palette → Role → Semantic 引用链。系统字体栈与数字字体回退继续沿用。移动端字号和字重以用户确认的 [typography.md](typography.md) 为准，Regular 为 400、Medium 为 500；原 PC 字重规则不再作为移动端的优先依据。不加载网络字体。
具体字体和颜色见 tokens.json；来源快照与 SHA256 见 tokens/sources/。

## 移动端初始基线（历史实现）

以下尺寸反映初始化与现有实现；字体部分已由 typography.md 的用户规范接替，尚未批量迁移。
| 项目 | PC 来源 | 移动端 |
| --- | --- | --- |
| 画布 | 1440 × 900，最低 1280px | 默认 390px，检查 360/375/390/430px，真机流式 |
| 正文 | 14px / 22px | 16px / 24px；次要文字 14px / 22px |
| 紧凑数据标签 | 不直接沿用 PC 密度 | 报表卡片内辅助指标名称 11px / 20px、400 字重，适用于并列短标签；不用于正文、输入、操作文字或主要统计数字 |
| 按钮 / 输入 | 默认 32px | 按钮默认 40px 视觉高、40px 最小热区、8px 圆角、15px 字号 / 400 字重；输入框 48px |
| 触控 | 鼠标为主 | 点击区域至少 40 × 40px |
| 页面边距 | PC 宽画布边距 | 默认 16px，区块间距 24px |
| 导航 | 侧边栏与密集工具栏 | 顶部导航 48px；需要时底部导航 56px，均另加安全区 |
| 数据展示 | 表格 | 以列表行或卡片优先，复杂二维数据才横向滚动 |
| 选择与说明 | 下拉、悬停解释 | 点击触发底部弹层或独立页 |

数值是本次初始化决定的工作基线，尚未逐页评审。颜色、间距、圆角通过 token 引用。
布局优先 Flex，只有明确二维对齐使用 Grid。文本允许换行，长内容不得挤出操作区。
手机浏览器使用自己的状态栏；页面不重复绘制虚假系统状态栏。
