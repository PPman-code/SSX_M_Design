# 上拉层交互规则 · 2026-10-22

状态：2026-10-22 用户确认执行基线。已确认交互规则与实现迁移状态分开记录；不表示所有页面已完成迁移。

## 核心分类（用户已确认）

- 纯选择任务使用 selection 上拉层：显示顶部横杠，可下滑关闭。
- 编辑任务使用 editor：无横杠，不允许下滑关闭。多层级编辑进入下一层，顶部使用返回。
- 编辑表单中打开字段选项，仍采用选择交互，不因父级是编辑而变成 editor。搜索框本身不构成编辑任务。
- 编辑底部弹层打开的单选/多选层使用左上“图标＋返回”，右侧不显示关闭；仍带横杠、可下滑取消。返回表达回到父编辑表单，不代表编辑子页。
- 返回视觉沿用已确认规格：16px 图标、14px文字、4px间距、二级文字/图标语义色，40px热区。
- 已编辑内容退出时提供继续编辑/放弃修改；没有修改直接退出。

### 从选择进入新增编辑

选择层点击新增，是新编辑任务的第一层，不能仅因为它是第二个可见界面就认定为编辑子层。第一层指编辑任务层级，不代表只能显示关闭图标：有明确来源且要返回选择列表时可以使用返回；返回与关闭二选一。本次积分新增规则按截图确认采用返回。只有编辑表单再进入子编辑页，才增加编辑任务层级。保存新增项后返回原选择层并自动勾选，不提前提交父表单业务。

### 层级与返回

- 编辑层之间采用同一个任务容器内的页面切换，保持外壳高度稳定，不连续堆叠多个编辑弹层和遮罩。
- 选择器可以临时覆盖编辑层；打开后只允许最上层滚动和交互，关闭后恢复父层滚动、值和焦点。
- 有返回时不再同时显示右侧关闭；右侧保留等宽空槽，确保标题居中。返回退当前任务的一层，不直接关闭所有父层。
- Escape/浏览器内应用返回等程序化关闭应与可见返回/关闭采用相同草稿检查，不能绕过保护；浏览器刷新/离站拦截另行实现，不声称已支持。
- 不在选择器内同时提供返回、关闭、底部取消三个同义入口；具体选取仍按场景已确认结构，积分多选底部已确认为数量+确认。

### 草稿与取消

- 父编辑草稿、选择草稿、子编辑草稿分别维护，取消只丢当前层未提交内容。
- 即时单选再点当前项直接返回；可选字段必须能恢复未选择，例：批量修改的不修改、筛选的不限。
- 多选先在本层改草稿，确认后回填；下滑、遮罩、关闭均不回填，不应误触发父编辑的放弃提示。
- 退出选择层不必因勾选变化再弹一次放弃确认；编辑层的输入、删除条目等改动才需要保护。
- dirty应比较进入该层时的基线，改回原值后视为未修改；纯搜索、滚动、切换焦点不算编辑。
- 提交成功直接退出，不再提示放弃。请求中应防重复提交，并在提交反馈完成前阻止有冲突的退出操作。

### 触摸、键盘与布局

- 下滑关闭仅允许从顶部横杠或标题区域起手；正文、描述及底部操作区不参与弹层拖拽，即使正文已滚到顶部也不能下拉关闭。正文滚动、滚轮选日期不能误关闭。
- 软键盘弹出时，编辑层保持输入可见；返回/完成与关闭任务的语义区分，实际键盘交互需真机验证。
- 顶部导航56px，标准底部操作栏56px，安全区另加；仅正文滚动。列表选项48px；弹层首行Search外层48px/输入36px。
- 未完成键盘、安全区、微信WebView与触摸真机验证前，不宣称设备兼容通过。

## 加减积分对应流程

1. 学员页气泡菜单选加分/减分 → 直接进入独立积分项选择层，带横杠、右上关闭；此时不显示空编辑页，关闭/下滑/遮罩结束本次操作。
2. 勾选后确认选择 → 打开加/减积分编辑层，无横杠；未选时确认可点击并轻提示，保持选择层。
3. 编辑页添加积分项 → 第二层选择，左上返回、无右侧关闭，有横杠；底部数量+确认。返回取消本层选择草稿，恢复父编辑。
4. 任一来源的选择层新增规则 → 新编辑任务的第一层，无横杠、左上返回；保存返回原选择层并自动勾选，不提前改变学员积分。
5. 积分项确认后可调整分值、原因、移除。只有在编辑层移除全部积分项后显示空编辑态，可再次选择；选择层空选确认不制造空编辑页。
6. 主编辑确认加分/减分 → 才提交本次积分变动。关闭确认归属当前Drawer任务上下文，Escape不应关闭确认后再次触发父层退出。

已保存到规则库的规则属于独立保存操作；退出积分编辑不删除该规则。当前仅页面内存模拟，不等于真实后端保存。

## 提交按钮与校验（用户确认，2026-10-22）

- 表单提交、保存、确认按钮默认保持可点击，不因未填必填项、选择为空或校验未通过而默认禁用。
- 点击后先执行校验，失败时阻止提交。具体问题在相关字段旁展示，必要时用Toast概括；定位并聚焦首个错误字段，不能只给泛化提示。
- 没有选择条目的批量操作，应提示先选择客户；批量修改没有设置字段时提示请选择至少一个需要修改的字段。积分项为空时提示先选择积分项。
- 校验失败保留全部已输入值与选择，不关闭弹层，不产生业务修改；补全后可以再次提交。
- 提交中防重复触发、权限限制、业务上确实不可用的操作仍可禁用或隐藏，但需解释原因。不能把“不知道还差什么”的问题留给不可点击的按钮。
- 此规则已确认；2026-10-22已迁移积分主确认、客户批量修改保存、客户无选择的批量动作和空列表批量入口。其他调用仍需按场景审查，不能移除底层Button的disabled能力，也不能宣称全站所有校验已完成。

## 后一层高度变化（用户确认，已迁移BottomSheet）

- 不使用露出前层半截标题、两个圆角顶边的卡片式堆叠。
- 任一时刻只显示当前任务层完整外壳：编辑层内切换沿用稳定外壳；临时选择层显示时遮蔽父层外壳，退出后恢复父层高度、滚动位置、草稿和焦点。
- 子选择层可按内容自然增高，但不得越过安全区；长内容只滚动正文，头部和底栏保持固定。不要为了适应父层高度而裁剪选项。
- 不能通过卸载父表单实现视觉隐藏而丢失草稿，也不能让被遮蔽父层继续响应点击或下滑。
- 已通过Base UI的data-nested-drawer-open状态隐藏父BottomSheet外壳（透明且不接收指针），保留挂载，不改父层高度和草稿。子层关闭后恢复。适用于本地BottomSheet嵌套，SideDrawer和居中Dialog各自保留对应外壳语义。

## 积分主编辑层高度（用户确认 · 2026-10-22）

加减积分主编辑层内容少时自然撑高；内容多时最大高度取可用视口高度减顶部16px留白（与顶部安全区取较大值）。扣除预览导航/底部占位及虚拟键盘占位，不再受85dvh上限约束。达到上限后仅正文滚动，标题与底部操作固定。当前迁移范围仅积分主编辑层；纯选择层及其他编辑层不视为已迁移。

## 单选层返回与取消用语（用户确认 · 2026-10-22）

- 从编辑底部弹层进入字段单选：优先“返回”，复用14px文字、16px左箭头、4px间距、二级文字/图标色及40px热区。右侧仅等宽空槽，标题居中，不再出现关闭或重复的顶部取消。
- 独立选择任务没有父编辑路径时，可用“取消”表达放弃选择；不因统一文案强行增加返回层级。底部取消仅在该场景确有需要时保留，不与顶部同义入口重复。
- 单选保持selection：横杠、下滑取消、遮罩及Escape只退出当前选择；父表单输入、已选值与滚动/焦点恢复。即时单选选中回填父草稿并返回；需确认的单选在确认前不回填，返回取消本层草稿。
- 实现迁移：BottomSheet提供可选onBack；客户批量修改状态/校区已接入，其他默认入口不变。不影响已确认的积分多选“数量＋确认”结构。
