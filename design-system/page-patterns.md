# 移动端页面模式

独立手机路由 /mobile，工作区 /，交付 /handoff（均为 HashRouter 路由）。初始化只含组件预览。

列表：标题与搜索/筛选 → 主要列表 → 加载更多/结束反馈。每行主信息优先，辅助信息换行；不缩小 PC 表格冒充移动布局。
表单：顶部返回与标题 → 标签置顶的字段组 → 保存区。说明必填、即时/提交校验、失败恢复和未保存离开行为。
详情：状态与主信息 → 分组内容 → 主操作。底部固定区预留安全区和内容避让。
选择器：短列表用底部弹层，长列表加搜索或独立页，区分即时选择与确认提交。
全页面依场景覆盖正常、加载、空、错误重试、无权限和禁用状态。
PC 工作区与手机产品页分离；手机直接打开 /mobile，不显示桌面设备边框。
