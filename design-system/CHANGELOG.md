# 变更记录

## 0.1.0 · 2026-10-12
用户确认初始化移动端设计项目，规范大致沿用 PC 并调整端差异。
继承 PC 的三层颜色、系统字体、字重、间距、圆角、图标快照与 token 生成器。
新增移动端初始基线：390px 默认画布、360–430px 检查、48px 控件、44px 触控、16px 正文、安全区、底部弹层、独立手机预览。
初始页面为工具与组件示例，不代表正式业务页面或真机兼容已验收。

移动端可读性调整：新增 color.mobile.action 与 color.mobile.status；Light 主操作采用品牌 800，Dark 主操作采用品牌 200 配深色文字；状态文字选用既有较深色阶，警告用深色文字和橙色标记。辅助文字/占位符 Light 调整至 neutral.800。物理色板保持来源快照不变。
