# 移动端交互

- 顶部布局与吸顶分开定义，遵循 [页面层级规则](page-patterns.md#顶部层级滚动与底部工具栏已确认)：第一层 56px、第二层 48px、数量/批量操作层 40px。常见上滑是第一层移出、只第二层吸顶；第二层吸顶后仍为 48px。第三层随内容滚动；已有明确的单栏吸顶要求保留。不能把初始位于顶部的多栏一并固定。标准单行底部工具栏 56px，安全区另计。

- 移动端组件只提供 pressed、focus-visible、disabled 等必要状态，不提供 hover 状态；桌面手机预览同样不展示悬停效果。点击说明入口，不使用悬停触发。
- 触控热区与排版保护：所有独立操作触控区域至少 40 × 40px（`--layout-touch-target`）。
  - **热区扩展伪元素（`.touch-target`）使用规则**：仅在控件本身的实际物理/渲染点击尺寸小于 40px 时（如纯图标按钮、输入框清除图标、密码可见性切换、行内重试文本、独立小尺寸开关等），才允许使用 `.touch-target`（通过绝对定位伪元素扩展至 40 × 40px）。严禁直接设置 40px 宽高配合负 margin 抵消排版，避免破坏 flex 盒模型与对齐。
  - **无需热区伪元素场景**：当按钮或点击整行自身的物理尺寸（宽高、或由 padding 撑开的点击盒模型）已达到 40px 及以上时（如普通 `Button`、带文字的表单行 `Cell`、选项整行 `Checkbox` / `Radio`、卡片整体等），**不得额外添加 `.touch-target` 或伪元素**，防止热区向外溢出造成相邻按钮、卡片操作条或上下列表项之间的点击判定重叠与误触。
- 弹层使用本地 BottomSheet 封装 Base UI Drawer；有标题、关闭入口、遮罩、滚动锁定和焦点恢复。
- 居中说明弹窗使用本地 InfoDialog 封装 Base UI Dialog，底部「知道了」为关闭入口；同样支持遮罩、Escape、滚动锁定和焦点恢复。
- 有确认按钮的选择器保留草稿；取消、遮罩或关闭不提交，确认才更新外部摘要。
- 输入 16px 起，合适的 inputmode/autocomplete；标签始终可见，占位文字不替代标签。
- 高度使用 dvh，底部预留 env(safe-area-inset-bottom)，滚动区 min-height:0；固定操作区必须有内容避让。
- 底部弹层含表单时使用 VirtualKeyboardProvider，并真机验证键盘出现/消失与焦点滚动。
- 列表刷新、分页或加载更多需明确边界，不默认全量下载；提交防重复，失败保留输入并可重试。
- 初始化示例只有内存状态，不宣称已保存到服务端。
- 尊重 prefers-reduced-motion；拖动关闭必须同时有可点击的关闭入口。

- 选择、日期和筛选弹层共用 BottomSheet 外壳，有确认操作时通过 footer 放置固定操作区；页面不嵌套第二个选项滚动区。移动端页面与弹层隐藏滚动条，保留正常滚动；桌面工作区滚动条不受影响。

- 桌面微信外观预览中，微信顶部栏和底部浏览导航 / Home 指示条是外部容器，中间的 product-scroll 才是项目应用视口。所有业务弹窗、遮罩、入场/退出及拖动动画都必须限制并裁切在这个视口内；底部弹层从下方微信外壳后面滑入/滑出，不遮挡或压暗外壳。新增模态组件应复用公共视口边界，不另设覆盖整个模拟屏幕的遮罩。真实手机仍由微信提供外壳，不绘制模拟栏。

- 即时单选弹层：已选项右侧仅显示勾，无空心圈和底部取消/确定；点击即提交并关闭，包括再次点击当前选项。需确认单选：使用圆点单选标记及草稿确认，不用圆圈内对勾。

上拉浮层操作栏按用途统一：筛选用重置/确认；需确认单选和多选用取消/确认；即时单选无操作栏。取消、关闭和遮罩不提交草稿；重置只修改筛选草稿。标题 16px，关闭图标 18px，点击区域至少 40px。

WheelPicker 本体不带按钮；内联可即时更新，弹窗中的单列、多列和联动通过 Picker 顶部的取消/标题/确认操作草稿；无底部按钮或右上关闭，确认提交，取消、遮罩或 Escape 保留原值。方向键、Home/End 与触摸滚动均可选，跳过禁用项，滚动停止后居中；日期等业务联动规则由调用者处理。原生滚轮局部滚动保留，不能因隐藏滚动条而禁用。

下拉刷新（2026-10-21 已实现候选）：已有业务页面通过 MobilePage 的可选 onRefresh 接入，不更换滚动容器或清空业务状态。只在顶部识别单指向下手势；横向/向上/多指取消，输入区域保持原生交互。刷新时防重复，失败保留现有内容；卸载取消异步回调，键盘有等价入口。六页当前只执行本地模拟刷新，手势参数及设备表现仍待真机验收，细则与迁移范围见 components.md。
