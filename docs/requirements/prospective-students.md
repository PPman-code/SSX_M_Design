## 页面及行为

入口为首页常用功能「意向学员」，固定路由 /pages/prospective-students/v1，工作区 ?page=prospective-students；继承 theme/chrome；独立打开及手机预览不绘制返回/标题导航，直接从搜索工具栏开始，页面标题由 document.title 提供；工作区 chrome=wechat 继续显示模拟微信导航。右侧配置只显示当前页面名称/版本，不新增专属配置项。

- 列表搜索姓名、电话、公立学校；数量随搜索及筛选更新；数量栏高度与学员管理统一为 40px。卡片头像可取图片，无图片使用姓名首字；姓名省略；性别、实际状态、手机号、主责任人、意向级别、上次沟通、下次跟进按 PRD 展示。未设置的主责任人/级别/上次沟通留空，下次跟进为「待定」；今天橙色，跨年补年份。
- 电话及主页箭头独立点击；按用户 2026-10-20 对照 Figma 的修正，电话图标移至号码右侧同行，主页箭头单独位于卡片右侧，取消原型中两图标间的短竖线。电话图形 14px，保留 44px 点击区域。查看资料独立入口。
- 批量模式卡片整体可勾选，暂停卡片业务操作并收起搜索/排序/筛选；底部面板为正常布局流中的 footer，不使用遮罩，列表可以滚动至最后一张。全选范围为当前搜索/筛选结果。六个操作无选择时禁用，删除红色；取消退出并清空选择。
- 批量修改只应用已选择字段，状态和校区可搜索选择，返回/取消选择保留表单已选值；未选择任何字段不能保存。成功清空客户勾选并保持批量模式；失败保留表单和勾选；关闭放弃表单草稿但不清空客户勾选。
- 排序支持姓名/录入/下次跟进/最近沟通/意向级别，重复选择切换方向。当前字段有方向和勾选。
- 右侧筛选抽屉限定在产品视口内。归属、客户信息、三组日期、可配置自定义字段分组；「更多条件」在配置为空时不渲染。跨字段交集，多选值并集，日期包含边界、支持单边、空日期不匹配已设置的日期条件。开始晚于结束时阻止提交。
- 打开筛选复制当前条件为草稿，确定才生效；重置只改草稿，关闭丢弃未确定内容。

## 本地模拟与接口边界

当前是 React/Vite 可交互设计原型，数据在组件内存中，不调用生产 API，不持久化。刷新恢复五条示例客户。批量修改和删除仅改变当前预览数据。

PRD 要求沿用的客户主页、基本信息、添加客户、转正式/取消转化、两类试听流程在本仓库中没有可复用的实现。保留入口并提示到现有业务系统办理，不新造流程，不显示虚假的办理成功；真实集成需传递客户 IDs 到既有系统服务。

本地手机号完整时使用 tel: 链接；脱敏示例不暴露电话链接。真实客户查看范围、下属范围、号码可见性、每项操作权限、状态限制、可批改状态和校区，均必须由服务端/用户配置返回；前端示例数据和允许操作列表不作为权限真相来源。

本地筛选配置提供「意向课程」多选示例。组件支持 text/date/single/multiple 字段元数据，并根据配置渲染，空配置隐藏整个更多条件分组。服务端自定义字段类型及特殊过滤逻辑仍需按实际字段契约对接。

旧查询排序交给服务端，无法仅从前端源码确认姓名、空值和排序默认方向。当前设计模拟采用录入日期降序、中文本地化姓名排序、空值置末；上线对接必须沿用后端真实规则，不能将这三项模拟规则宣称为现有业务规范。

测试场景可通过直达页面查询参数访问，不在右侧添加控件：state=empty/error/forbidden，phone=masked，save=error。仅用于验证空/错/无权限/号码脱敏/保存失败行为，不是生产权限机制。
