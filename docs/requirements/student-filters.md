# 学员管理筛选 · 本地原型

2026-11-02 用户提供线上两张字段截图，要求按意向学员筛选规范改造；变更 D/V/I/B（本地筛选逻辑）。截图只作为字段清单，不继承其中字号、间距和图标规格。

## 对照与范围

共同项：SideDrawer、56px Cell、Search + BottomSheet + SheetSelectionList、SheetChoiceGroup、DateRangeFields、SheetActions。父抽屉/子选择独立草稿，子确认只回填父草稿；父确定才应用，取消不保存，重置只清父草稿。

业务差异：学员按校区、班级、任课老师、剩余数量和学费筛选；不引入意向客户的意向级别、招生来源、备注等字段。旧学员筛选只有状态、学费正负和有效期，字段不完整；本次用截图字段替换旧的学费正负与有效期选择。

## 字段

| 字段 | 交互与含义 |
| --- | --- |
| 查看学员范围 | 全部学员 / 自己名下学员，单选，默认全部 |
| 校区名称、班级名称、班级任课老师 | 56px选择行，可搜索、多选、取消/确定，不限可清空 |
| 学员性别 | 不限 / 男 / 女，单选 |
| 学员状态 | 平铺多选，与本地4种实际状态一致；不限清空状态条件 |
| 剩余数量、剩余学费（元） | 最低/最高区间，可负数、小数及单边界；最低高于最高或非数值时阻止提交、提示并聚焦最低值 |
| 期段、类型 | 平铺多选，含不限清空；同一条模拟课程记录满足所选期段与类型，各字段之间取交集 |
| 沟通时间 | 上次沟通日期区间；DateRangeFields及快捷时段，默认不限 |
| 出生日期 | 完整年月日区间，无近期快捷项，默认不限 |
| 生日 | 仅选择月日、忽略年份，支持跨年及2月29日；日期选择层紧凑说明，无年份列及近期快捷项 |

用户明确要求“按课程类型过滤费用”先不做，不显示开关，也不增加对应统计逻辑。类型只匹配课程记录，数量与学费使用学员合计值；列表数字不随筛选改成课程统计值。

## 数据边界与待验收

student-filter-data.ts提供固定ID绑定的校区/班级/任课老师/模拟归属、沟通和出生日期、期段/类型记录。字段选项为演示配置，不代表完整线上词典。自己名下仅由本地own标记演示，不是权限隔离。所有条件为字段间AND、多选字段内OR；空边界不限，带时间条件时排除缺失日期的样本。

没有连接生产接口，不改变列表身份ID、业务动作或持久化。生产需由后端提供授权归属、课程关系、选项词典及真实日期。真机键盘、滚轮、WebView和真实权限未验收。
