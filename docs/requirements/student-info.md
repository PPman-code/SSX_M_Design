# 学员信息与加减积分原型

2026-10-22 用户授权，变更级别 B/I/V/D。学员信息正文仍保持骨架；扩展加分及减分操作，依据用户四张流程原型，视觉使用项目规范和本地组件。用户随后明确弹层内不需要加/减积分 Tab，已移除。

## 入口与组件

- 路由 `/pages/student-info/v1?student=<id>`，使用学员管理稳定样本 id，保留 theme/chrome/from。无效身份禁用积分入口。
- 页面正文暂缓；底部 56px 操作区（安全区另加）使用 40px 圆角 Button，带箭头 PopoverMenu 图标20px、文字16px。
- 菜单加分/减分直接进入独立积分项选择层（右上关闭），确认非空选择后进入编辑；积分清零仍为待设计提示。
- 三层弹层全部使用 BottomSheet 默认标题/关闭、SheetActions（56px 工具栏/40px 按钮）；不复制原型自定义标题栏，无加减 Tab。
- 学员/余额/合计使用 Cell/CellGroup；输入使用 Input 基础56px行，必填在标题右侧；类型使用 SheetChoiceGroup 40px；规则库使用 Search（48px行/36px框）和 SheetSelectionList 多选48px行，右侧勾为系统既有样式。
- PointsAdjustment 仅为页面流程组合，不注册为 Recommended 公共组件。

## 操作与草稿

- 四条模拟规则：课堂表现积极+3、按时完成作业+2、课后练习优秀+5、其他奖励不限分值。余额初始为模拟128分，与真实学员余额无关。
- 规则库搜索保留勾选；取消不回填，确认选择回填主草稿；重新打开库同步已选项。保留原有项已编辑的分值及原因；移除不删除规则。
- 新建规则名称必填且不可与现有规则重名；固定分值需默认值，不限分值不设默认值；原因选填。返回/关闭丢弃未保存规则；保存将规则加入本页内存库、自动勾选并返回库，仍需“确认选择”后进入本次操作。
- 主草稿每个分值可编辑，原因选填；无选项或任一分值无效时禁用确认。取消/关闭主弹层不加分，下次重开为新草稿。
- 当前原型校验采用大于0正数，按百分之一分整数累计避免小数误差，并校验安全数值范围。这是模拟实现边界，不自动升级为生产业务契约。
- 只有主弹层“确认加分”更新该学员本页内存余额，防重复提交并显示“模拟加分成功”。初始128分、规则和变更均未连接生产接口，无持久化，刷新/离开页面后重置。新规则保存与积分提交是两个独立步骤。

## 验证边界

- 覆盖明暗主题、360/390/430px、嵌套草稿取消、搜索、新建规则、固定/不限分值、校验、移除、合计和模拟提交、关闭回焦。
- 桌面浏览器不等于真机验证；真实微信 WebView、软键盘、实际安全区仍需设备验收。

## 减积分扩展（2026-10-22，B/I/V/D）

- 加分、减分复用一个 PointsAdjustment，通过 operation 决定标题、标签、符号和提交方向，不添加弹层内Tab。
- 加减规则库分开保存；减分默认迟到1分、未带学习用品2分，库内分别显示−1/−2。新建规则只加入对应类型库，重名校验也在该库内执行。
- 减分输入填写正的扣分数值，复用大于0/两位小数校验；合计用负号展示，主确认时只做一次负方向累计。
- 用户明确允许扣成负数，不以当前余额限制本次扣分；例如128分扣129分后为−1分，并与加分共用该学员的本页模拟余额。
- 确认减分使用 Button danger，经 SheetActions primary.tone 透传；禁用、40px按钮、56px工具栏仍使用系统规格。主确认后提示“模拟减分成功”。
- 搜索、多选、新建固定/不限规则、取消、回填、编辑、原因、移除、回焦与加分一致；清零及记录页不在本轮。
