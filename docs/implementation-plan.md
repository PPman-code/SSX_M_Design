技术：React / TypeScript / Vite / Base UI / CSS，参考 project-setup-proposal.md。

## 文件与边界

- design-system/ 是规范源；scripts/generate-tokens.mjs 生成 src/styles/ 与 src/handoff/ 中的受控文件。
- src/components/ui/ 封装底层库；页面只使用本地组件。
- src/pages/ 分别负责工作区、组件预览和规范交付；业务页面清单初始为空。
- vite.config.ts 仅在开发模式提供本机私有 IPv4 地址；静态发布用当前站点地址。
- 初始模拟界面不接入账号、权限或真实数据。

## 验证重点

1. 360px 窄屏和长文本不得意外横向溢出。
2. 底部弹层关闭后恢复焦点，取消不提交选择，确认更新摘要。
3. 主题同步到 iframe，独立链接刷新仍可访问。
4. 局域网地址不可用时明确提示，不能把 localhost 二维码称为手机可访问地址。
5. token 引用完整、生成物一致；移动端尺寸不能残留 PC 的 1280px 最小宽度。

实测设备的软件键盘、刘海安全区和微信 WebView 保留为真机待验收，不以桌面模拟代替。
