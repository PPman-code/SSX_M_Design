# 我的 · v1 · 设计草稿

来源：[师生信汇总 Figma 节点 6001:2456](https://www.figma.com/design/lrjKupwY2XZhLxCijHNkr9/?node-id=6001-2456)。使用角色：班主任。目的：查看个人身份，进入报名、收款、招生、考勤与个人服务功能。

工作区：/#/?page=my；手机页面：/#/pages/my/v1。设计对照：增加 ?chrome=wechat。

当前范围：正常登录状态的页面视觉、内部滚动、固定底部导航，以及入口点击反馈。未提供下级页面及“仅收款”说明文案，点击后使用明确的设计预览提示，不调用相机、收款或后端。头像、姓名与身份是设计示例数据。

页面顶部渐变、玻璃收款卡片、56px 功能行、50px 标签区域与彩色图标按原稿保留。微信状态栏、导航栏和 iPhone 横条仅为可选预览外观，不在手机默认链接中重复绘制。真实页面使用 safe-area，底部标签整个区域可点击，不整页缩放。

页面特有色值按原稿进入独立角色，不改变共享品牌色。Dark 为工程预览适配，原稿只有 Light，尚未经设计确认。原稿低强调底部标签颜色与 10px 字号本版保留，作为此版还原的局部例外，正式规范评审需确认可读性。

检查范围：360/375/390/430px 无横向溢出，内容可滚动至最后入口且不被底部栏遮挡；手机二维码打开当前版本，默认无模拟系统栏。真机安全区、微信容器及软键盘尚未验收。

2026-10-12 验证结果：pnpm check、pnpm build 和 18 项浏览器测试通过；375px 实际截图已对照 Figma 原稿。资产列表及哈希见 my-v1-assets.json。
