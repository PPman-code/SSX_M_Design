# 出勤率报表 · v1 · 设计草稿

来源：交互稿 `移动端出勤率最新.html`（智校 · 移动端出勤率报表），由用户提供，无 Figma 节点。使用角色：班主任（可模拟老师、学管师、校长）。目的：按维度汇总本人范围内的出勤率，并下钻到课次明细。

工作区：/#/?page=attendance；手机页面：/#/pages/attendance/v1。入口：首页 v1「报表中心 → 出勤率」；「我的」页不再显示重复入口。设计对照：增加 ?chrome=wechat。

当前范围：报表主视图（整体概览、维度汇总、分组比较、行内展开统计）与课次明细分视图。身份、日期、筛选与取值均为设计模拟状态，不连接后端。

## 实现内容

- 标题由 document.title 提供，业务页不绘制微信导航；桌面微信外观通过预览外壳显示动态标题及浏览历史。
- 复用 `MobilePage` 的微信外观预览：通过 `?chrome=wechat` 显示系统状态栏、微信导航栏与底部 Home 指示器；手机页面不绘制模拟外壳。
- 统计范围说明随身份变化；老师身份额外提供「主教／助教」授课身份筛选，且至少保留一项。
- 统计时段：本月、上月、最近30天三个快捷项与自定义起止日期；起止非法时提示且不提交。
- 整体概览：出勤率、补课后出勤率、上课次数、人次数、试听。试听数量独立展示，是否计入比率由学员范围包含条件决定。
- 汇总维度：班级名称、课程名称、班级标签、上课校区、年份、期段、年级、科目、类型、班型；取值可多选并支持班级名称、课程名称搜索。
- 分组卡片：分组名、校区、上课次数／人次数、出勤率、补课后出勤率；卡片内展开显示计费／未计费／比率与补课后出勤率，可进入课次明细。
- 课次明细：按日期倒序，展示日期时间、班级、任课老师、实到／应到与试听，并复用同一张统计表。
- 分组与明细均采用上滑加载（每页 4 组 / 6 条），全部加载后给出结束反馈。

## 与原稿的差异

- 未复刻身份选择页与老师首页（含九宫格入口），这两屏属于入口上下文，本项目由「我的」页进入；身份作为设计模拟放在工作区右侧页面配置，通过 ?role= 传递。
- 顶部导航栏沿用项目浅色导航与返回箭头，未复刻原稿深色外框与「···」。
- 日期、筛选、取值三个浮层统一使用本地 BottomSheet（底部弹层），未复刻原稿的右侧抽屉与 details 下拉；内容项与原稿一致。
- 原稿的整页渐变背景、玻璃质感与固定色值未引入，页面使用项目语义 token（--color-*），因此视觉上比原稿更中性。
- 示例姓名沿用「我的」页的「用户名称」；原稿为「刘亦菲 · 黎璐教育集团」。
- 数据为本地示例（12 个班级、按今天相对回推的课次），取消、撤销与未上课课次保留在数据里用于验证不计入报表。

## 页面特例

- 未为出勤率报表新增 token；页面仅消费既有语义 token 与本地组件。

## 检查范围

360/375/390/430px 无横向溢出；展开行、课次明细、三个弹层在各宽度可用；无权限身份显示空态；工作区切换身份后 iframe 继承状态。真机安全区、微信容器与软键盘尚未验收。

## WorkBuddy 产出复核 · 2026-10-14

修正非法 role 参数回退，避免落入学管师范围；补课人次只补充原本缺勤且补课出勤的学员，避免重复提高补课后出勤率。保留滚动加载并增加可点击加载入口，重新观察加载哨兵；搜索无匹配时明确反馈。无权限隐藏空范围说明，工作区没有 Figma 来源时不渲染空链接。

角色、示例计算和前端筛选经测试，不代表真实后端口径已验收；尚未接入生产接口。原稿身份页面由新首页设计模拟切换承接。

微信外观预览只显示容器导航：关闭、动态标题、域名、更多；底部按导航历史显示后退/前进。明细使用 view/group URL 参数，后退可回报表、前进可回明细；手机访问不绘制这两处微信外壳。

## 旧稿风格迁移 · 2026-10-14

视觉参考 Figma 师生信汇总(新) 续费率报表 hoN0voWKmRtnWBPuzMw1yB / 4195:60491，迁移到出勤率而非新增续费率业务。顶部品牌蓝渐变约 350px 内衰减，复用旧稿 Subtract 原始装饰资源；概览使用浅蓝到白的 8px 卡片。分组从密集表格改为独立卡片，每卡显示维度标识、名称、校区及四项统计，展开、明细和全部筛选逻辑继续保留。数字继续 numeric 栈，不照搬旧稿 MiSans。统计比率统一品牌语义色，不新增未经确认的好坏阈值。

维度标记仅用于班级名称与课程名称，分别复用最新 Iconfont 的选班 xuanban1 / 选课 xuanke1；其他维度不保留图标占位。

分组卡片使用公共 Collapse / CollapseItem 的 card 变体，摘要常驻，详细统计由 Base UI 折叠面板控制；一次展开一项，原筛选重置展开状态逻辑保留。

卡片摘要中的上课次数、人次数、出勤率、补课后出勤率标签统一 11px / 20px、400 字重，采用移动端紧凑数据标签规格；统计数字仍为 16px numeric 字体。

## 汇总工具栏与统计说明 · 2026-10-14

分组统计标题与数据条数独立成行，下方维度和范围采用并排的 44px 选择控件。概览卡片上下内边距为 12px、左右 16px；角色统计范围说明移至整体概览旁的问号入口，复用本地 Popover，点击查看并支持外部点击或 Escape 关闭。统计与筛选逻辑不变。

统计说明使用深色 Popover 外观，问号入口使用灰色语义图标颜色；明暗主题均保留深色气泡与白字。

报表日期、筛选、范围三个选择弹层共用 BottomSheet 的固定标题与 footer；原快捷日期即时应用、筛选和多选草稿确认规则保留。多选项只在公共内容区滚动，不再嵌套滚动区。

短内容报表铺满内容视口，容器与渐变结束色统一使用 color.background.page，避免底部露出不同底色。桌面微信外观预览的模态层只覆盖业务区域，顶部浏览栏与底部浏览导航、Home 指示条保持在弹层外；独立手机地址不添加模拟外壳。

汇总维度入口显示“按照 xxx 汇总”，使用 BottomSheet + Radio list 即时单选，无取消/确定操作区；已选项右侧仅显示勾，点击立即应用并关闭，关闭按钮/遮罩不更改维度。应用沿用 changeDimension 的清空范围与展开逻辑。

## 展开区信息层级调整 · 2026-10-14

分组展开区使用“出勤明细”标题，避免重复维度名称；试听数量为次要标记。统计表去掉表头底块，使用 11px 列标题、14px 分类文字与 16px numeric 数值，增加行间距并以轻分隔线对齐计费/未计费/比率。补课后出勤率为独立收尾行，查看课次明细保留无底色灰色入口。样式仅作用于分组展开区，课次详情中的 StatsTable、计算与跳转逻辑不变。

## 分块明细方案落地 · 2026-10-15

按用户选中的第一个方案，将分组展开区改为出勤/缺勤两个分块，展示总人次及计费/未计费构成。缺勤率作为辅助文字紧跟“缺勤”标题，“其中已补”嵌套在缺勤内，避免暗示可与缺勤相加。上方摘要保留两种出勤率，展开区不重复补课后出勤率；课次详情原表格继续保留。计算口径、筛选、路由不变。

计费/未计费构成行右对齐放在总人次下方；该行数值与标签均为普通字体、12px / 22px、400 字重，不使用数字专用字体。

缺勤率调整到计费/未计费同一辅助行，统一普通字体 12px；构成行与上方标题/人次的间距从 8px 收紧为 2px，横向间隔 16px，窄屏允许按完整字段换行。

用户澄清对齐目标为底部“查看课次明细”入口：保留左文字/右箭头，为入口增加 12px 上内边距，与卡片底部已有的 12px 留白平衡，使分隔线到卡片底边之间的内容视觉居中。统计区保留调整前布局。
