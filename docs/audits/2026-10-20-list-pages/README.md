## 结论与迁移清单

整体共用 MobilePage、SideDrawer 等基础容器，身份信息层级已较接近。剩余差异集中在工具栏几何、留白、标签、图标主题与触控边界。以下为 2026-10-20 审查快照，当时均为 **待迁移**。后续状态见本文末尾迁移记录，不据此认定当前页面仍全部未修复。

| 编号 / 优先级 | 当前证据 | 影响及建议 |
| --- | --- | --- |
| L01 / 高 | 学员搜索栏实测 51px，客户 60px；搜索框 34px / 38px，圆角 4px / 8px；输入均 14px。见 Light 列表和两页 CSS | 同类操作密度不同，且输入小于现有 16px 规则；学员清除按钮 28×34px，客户最小宽 28px，均未明确满足独立操作 44×44。统一紧凑搜索变体，先复核输入、清除和相邻工具按钮命中区域；不能只统一外观 |
| L02 / 中 | 数量栏两页实测均 40px；学员左右 16px、行高 20px，客户左右 12px、行高 24px；卡片间距 12px / 10px | 高度已遵循用户要求，边缘与节奏仍有差异。候选统一左右 12px、行高 20px、卡片间距 12px；客户批量按钮高 44px，扩展区域需检查，不可为固定条高缩小触控 |
| L03 / 中 | 学员状态标签 10px / 14px，上下各 1px，实高 16px；客户 10px / 16px，实高 18px | 同类徽标高度不一致；候选统一 18px 总高。状态意义及颜色映射保留各自业务，不强行统一为一个状态表 |
| L04 / 高 | 学员搜索/电话/箭头等使用页面 SVG，并对整页 img 做 Dark 反色；客户多数使用公共 Icon，排序/筛选仍是静态 SVG。Dark 截图中客户工具图标较暗 | 相同角色的线条和主题处理不同。列出 ssx-design 对应项后迁到公共 Icon；缺项保留来源例外，不用近似图形替代。单色、彩色与头像分开处理；本轮未量测对比度，不声称通过 |

## 不应因统一而删除的差异

客户的三列跟进信息、批量操作、添加入口与学员的四列财务/有效期、分类 Tab、二维码/课程入口分别保留。学员仅 Tab 吸顶，客户当前工具栏吸顶，不能借 V 视觉调整改写此交互。财务负值、状态定义和排序字段仍由各自需求控制，不因相似卡片推导业务规则。
